# Unity Project 01: Solar System

**Submitted by:** David john

## Purpose
This project is an interactive 3D simulation of our solar system developed in Unity. It demonstrates celestial orbits, axial rotation algorithms, skybox lighting, audio integration, and dual camera perspectives.

## How It Works
- **Planetary Revolutions & Rotations:** C# scripts calculate and update planetary orbits around the Sun along with independent axial rotations.
- **Camera Controls:** Supports toggling between an interactive free-look camera and an orthographic top-down view.
- **Audio & Visuals:** Includes realistic lighting and dynamic space background sound.
